# إدارة خطط التخاطب الفردية

تطبيق ويب عربي (Laravel + Blade + MySQL) لإدارة الخطط الفردية للتخاطب، بنك الأهداف، مراجعة المشرفة، تقييم الأهداف، واستخراج ملفّي PDF (الخطة الفردية وتقرير التقييم).

المسار: `/home/momo/dev/speech-therapy-plans`

## المتطلبات

- PHP 8.2+ مع امتدادات: `mbstring`, `intl`, `gd` أو `imagick`, `pdo_mysql`, `zip`
- Composer و Node.js (لبناء واجهة Vite/Tailwind)
- MySQL 8+ (أو MariaDB) بترميز `utf8mb4`
- خط عربي لـ PDF (مُرفق نسخة مُهيّأة لـ mPDF في `resources/fonts/`؛ الافتراضي Noto Naskh Arabic)

## إعداد قاعدة البيانات

أنشئ قاعدة بيانات:

```sql
CREATE DATABASE speech_therapy_plans CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

انسخ الإعدادات:

```bash
cp .env.example .env
php artisan key:generate
```

عدّل في `.env` (بدون أسرار في `.env.example`):

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=speech_therapy_plans
DB_USERNAME=...
DB_PASSWORD=...
```

ثم:

```bash
composer install
npm install && npm run build
php artisan migrate
```

## إنشاء حساب المشرفة الأول

لا يوجد تسجيل عام. أنشئ المشرفة بأمر تفاعلي آمن:

```bash
php artisan speech:create-supervisor
```

سيطلب الاسم والبريد وكلمة المرور.

حسابات تجريبية (إن شغّلت الـ seeders):

```bash
php artisan db:seed
# أو بيانات وهمية إضافية بأسماء وهمية فقط:
php artisan db:seed --class=DemoSeeder
```

- مشرفة: `supervisor@example.com` / `password`
- مدرسة: `teacher@example.com` / `password`
- مدارس عرض إضافية: `demo.teacher1@example.com` … (نفس كلمة المرور)

## استيراد بنك الأهداف من ملف Word

ضع الملف المرجعي خارج `public/` (المسار الافتراضي):

`project-inputs/برنامج تنمية المهارات اللغوية.docx`

المجلد `project-inputs/` مستبعد من Git.

```bash
php artisan speech:import-goals-bank
# أو:
php artisan speech:import-goals-bank --path=/path/to/file.docx
```

الاستيراد آمن عند إعادة التشغيل (بصمة `fingerprint` تمنع التكرار). يطبع عدد الأهداف لكل مجال والصفوف التي تحتاج مراجعة.

نتيجة الاستيراد الحالية من الملف الأصلي: **428** هدفًا عبر **7** مجالات.

## توليد PDF

- يعتمد على **mPDF** مع دعم العربية وRTL وتشكيل الحروف.
- خطوط مُصحَّحة لـ mPDF في `resources/fonts/` (إزالة MarkGlyphSets من Noto).
- يمكن ضبط المسارات عبر:

```env
PDF_ARABIC_FONT_PATH=...
PDF_ARABIC_FONT_BOLD_PATH=...
CENTER_NAME="مركز السنابل المكية"
CENTER_DEPT="قسم التربية الخاصة"
```

- **PDF الخطة الفردية**: متاح بعد اعتماد الخطة (حتى قبل التقييم).
- **PDF تقرير التقييم**: متاح بعد اعتماد التقييم فقط.
- التحميل محمي بالصلاحيات (سياسات Laravel).

## الأدوار

| الدور | الصلاحيات |
|--------|-----------|
| المشرفة (أدمن) | إدارة المدرّسات والطلاب، مراجعة/اعتماد الخطط والتقييمات، كشف المتابعة، بنك الأهداف |
| المدرّسة | طلابها فقط، إعداد الخطط والتقييمات، إعادة الإرسال بعد الإرجاع |

## سير العمل

1. المشرفة تضيف مدرسة وطالبًا وتعيّنه لها.
2. المدرسة تنشئ خطة، تختار أهدافًا من البنك، تحفظ مسودة ثم ترسل للمراجعة.
3. المشرفة تعتمد أو تُرجع بملاحظة.
4. بعد الاعتماد: تحميل PDF الخطة، وبدء تقييم الأهداف.
5. المدرسة تقيّم (أتقن / في طور التدريب / غير متقن)، ترسل؛ المشرفة تضيف التوصيات وتعتمد.
6. تحميل PDF تقرير التقييم.

التواريخ في الواجهة والنماذج **هجرية** (يُوضَّح ذلك بجوار الحقول). التخزين النصي بصيغة `YYYY/MM/DD` هجريًا مع مساعدة تحويل عبر `App\Support\HijriDate`.

## ما نُفّذ وما اختُبر

**نُفّذ:** مصادقة، أدوار، طلاب (حذف منطقي)، بنك أهداف مع استيراد Word، محرر خطط، مراجعة المشرفة، تقييم أهداف، كشف متابعة، PDF عربي، أوامر Artisan، اختبارات ميزة.

**اختُبر فعليًا:** `php artisan test` (جميع الاختبارات)، استيراد البنك إلى MySQL (428 هدفًا)، بناء الواجهة `npm run build`، توليد PDF في الاختبارات، تدفق الواجهة الأساسي (لوحة، محرر الأهداف، حفظ مسودة).

**بيئة التشغيل المحلية المستخدمة للاختبار:** MySQL عبر Docker على المنفذ `3308`.
